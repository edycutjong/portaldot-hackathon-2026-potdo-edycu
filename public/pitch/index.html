07 // Key Features

Not Just a Wallet.
A Copilot.

⚡

Natural Language Tx

Type plain English. Get a structured, visual transaction preview. No hex, no confusion.

📦

Batch Airdrops

One command, multiple recipients. Wraps into a single utility.batch extrinsic for gas efficiency.

🛡️

Pre-Flight Protection

Insufficient balance? Card goes red, Execute disabled. No wasted gas. No surprises.

GUARDED AI PROXY

Delegate restricted execution authority to the AI agent. Send transactions without wallet popups — fully guarded by Substrate's proxy pallet.

ERROR TRANSLATION

Substrate error code 1010 → "Insufficient balance — you need 10 POT but have 8.5". Actionable suggestions included.

Five differentiated features. Natural language transactions, batch airdrops, pre-flight protection, guarded AI proxy for popup-free execution, and smart error translation. Existing wallets show what you're sending. Potdo shows what will change.
